# Recap Icon

Freigegeben: Entwurf A (2026-10-17). Sprechblase und Rueckblick-Pfeil
stehen fuer aufgezeichnete Gespraeche und spaeteres Erinnern.

- `Recap.svg`: editierbarer 1024-px-Master, deckend fuer Systemmasken auf iPhone/Watch.
- `Recap-mac.svg`: derselbe Entwurf mit transparentem Aussenrand und runder Kachel.
- `Recap.png`: deckender Export des Masters. Der Mac-Export liegt in `clients/macos/Resources/Recap.png`.
- `preview.html` / `preview.png`: die zur Entscheidung vorgelegten Entwuerfe A/B/C.

Farben: dunkles Petrol `#0E3540`, Tuerkis `#24D3B0` (Verlauf mit halber
Deckkraft), helle Sprechblase `#E8FFF8`, Pfeil `#0E746A`.
