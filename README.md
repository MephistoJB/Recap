# Recap

Recap ist eine native Swift-App fuer macOS: Aufnahmen importieren oder aufnehmen, lokal transkribieren, Sprecher zuordnen und Gespraeche in einer lokalen Bibliothek verwalten. Ein eingebetteter HTTP-Empfaenger nimmt Aufnahmen von iPhone und Apple Watch an.

## Herkunft

Recap baut auf [Owl von OwlAIProject](https://github.com/OwlAIProject/Owl) auf. Upload-Protokoll, vorhandene Clients, Datenkonzepte und bisheriges Icon stammen aus diesem Projekt. Die native Mac-App wurde fuer Recap in Swift entwickelt. Vielen Dank an Ethan Sutin, Bart Trzynadlowski und die Owl-Mitwirkenden.
